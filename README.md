# Psico-Supporto alle Vittime di Truffe

**Landing page informativa e di supporto psicologico per le vittime di truffe finanziarie online**

---

## Descrizione

Questo progetto è una pagina web professionale dedicata al supporto psicologico e informativo per le vittime di truffe finanziarie online. Include due sezioni principali:

1. **Psico-Supporto alle Vittime di Truffe** — Analisi delle 6 tecniche di manipolazione psicologica usate dai truffatori, con spiegazione scientifica del perché le vittime cadono nelle trappole e come il nostro team può aiutarle nel percorso di recupero.

2. **Buone Notizie** — Rassegna delle principali operazioni di polizia del 2024-2025 contro le truffe finanziarie online in Italia e in Europa, con statistiche aggiornate e un messaggio di speranza per le vittime.

La pagina include inoltre:
- Overlay SVG animato con simbolismo visivo (cervello, scudo protettivo, simboli valuta)
- Banner del libro "Rischio Trading" con link alle principali librerie
- Sistema di navigazione a pallini stile Olivetti
- Gate di registrazione con form sicuro (GDPR compliant)
- Petizioni al Parlamento Europeo per la tutela delle vittime
